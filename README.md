# Evolve Desk

一个从真实日常开始、由内置 Agent 协助行动，并能在审阅后持续改写自身源码的个人工作台。

项目主页：[github.com/Tabriage/EvolveDesk](https://github.com/Tabriage/EvolveDesk)

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`，在右上角连接设置里输入本地 OpenAI 兼容服务地址和密钥。密钥只保留在当前页面内存中，不写入代码或浏览器存储。

`pnpm dev` 会同时启动工作台和只监听 `127.0.0.1:4242` 的源码进化沙箱。

视频导入需要本机安装 `yt-dlp >= 2026.03.17` 和 `ffmpeg >= 6.1`；无字幕时的本地转录还需要 `whisper-cpp`。macOS 可以使用：

```bash
brew install yt-dlp ffmpeg whisper-cpp
```

首次使用本地转录时，在视频工作台中明确点击“下载多语言模型”。应用会从 whisper.cpp 官方模型仓库下载约 142 MiB 的 `base` 模型，校验大小与 SHA 后保存到 Git 忽略的 `.evolve/models/`；不会在启动时自动下载。

## 当前产品闭环

- **今日**：设置唯一焦点、添加和完成任务、建立轻量习惯。
- **统一收件箱**：先保存想法与链接，再决定是否转为任务。
- **视频总结**：支持 B站、YouTube、小红书和抖音；优先提取平台字幕，没有字幕时可用本机 Whisper 转录，也允许粘贴已有文本。总结包含一句话结论、时间戳章节、核心概念、创作拆解、知识卡片和建议任务。
- **知识证据台**：搜索并选择最多 12 张本地知识卡，向本机模型提问；回答必须保留有效卡片引用，资料不足时明确列出缺口，并可由用户确认保存问答或生成任务。
- **行动 Agent**：读取有限的工作台快照，把自然语言目标转换为结构化动作清单；只有用户确认后才写入本地状态。
- **自省记忆**：记录任务完成、输入整理和已经确认的 Agent 动作，解释工作台如何形成。
- **进化实验室**：在白名单源码内生成差异，逐文件审阅、固定验证并支持回滚。

任务、收件箱、习惯、视频总结、知识卡片、已保存问答和活动记录保存在浏览器 `localStorage`，当前不依赖账户或云端数据库。即使不连接模型，今日工作台也能完整使用。

## 当前安全边界

- 只允许连接本机 HTTP 模型服务（localhost / 127.0.0.1）。
- 行动 Agent 只能提出 `新增任务 / 设置焦点 / 保存输入 / 新增习惯` 四类结构化动作。
- 视频导入器只接受四个平台的显式 HTTPS 主机，使用固定 `yt-dlp` 参数且不经过 shell；它不能执行用户提供的命令或访问任意 URL。
- 本地转录限制单个视频最长两小时、音频最大 500MB；音频只存在于系统临时目录，完成或失败都会删除，不上传第三方转录服务。
- 模型必须拿到至少 80 个字符的字幕证据才会总结；标题和封面不能代替字幕。字幕只发送到用户配置的本机模型服务。
- 知识问答一次最多读取用户选中的 12 张卡片；结论引用会在服务端重新匹配真实卡片编号，无法匹配的模型引用不会进入结果。
- 源码 Agent 可以在白名单目录中提出源码变更；它不拥有终端工具。
- 源码变更经过路径、敏感信息、危险能力和文件哈希四重检查。
- 所有改变先逐文件预览、后确认；写入后自动执行固定检查。
- 个人工作数据只保存在当前浏览器的 localStorage。

## 源码进化与回滚

进化实验室目前允许修改产品界面、组件、纯本地功能状态、样式、测试和 README。模型连接、Agent 服务、依赖、构建配置、环境变量与 Git 元数据永远不在可写范围内。

每份源码提案保存在本机忽略目录 `.evolve/` 中，包含原始文件、目标文件、哈希和审计事件。如果变更导致页面无法使用，可以在终端回滚最近一次已应用提案：

```bash
pnpm evolve:rollback
```

也可以在命令后附加提案 ID，回滚指定提案。

## 下一阶段能力路线

视频总结闭环已经可用，后续继续补齐：

1. 教程类视频的关键帧、OCR 与画面理解。
2. 自动关联旧知识和周度学习回顾。
3. 提案分支、自动提交和远程协作审阅。

联网抓取、上传文件、Git 提交和远程协作都必须保持独立授权，不能由模型自行开启。
